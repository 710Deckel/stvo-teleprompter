📚 Anleitung

🔄 GitHub Auto-Sync

Beim ersten Öffnen erscheint ein Popup wo du deinen GitHub Token eingibst. Danach kannst du mit "🔄 GitHub Sync" deine Änderungen mit dem Team teilen!

1️⃣ Paragraph erstellen

Klicke im Editor-Tab auf "➕ Neuer Paragraph". Der Paragraph wird in der Liste gespeichert und bleibt dort dauerhaft.

2️⃣ Bearbeiten

Klicke auf "📝 Bearbeiten" bei einem Paragraph. Es öffnet sich ein Editor mit 4 Spalten:

  • 🔵 StVO Original - Der Gesetzestext
  • 🟢 VwV-StVO - Verwaltungsvorschriften
  • 🟡 Erläuterung - Allgemeine Erklärungen
  • 🟠 Moderationstext - Deine eigenen Podcast-Texte

3️⃣ Mit Team synchronisieren

Klicke auf "🔄 GitHub Sync" um deine Änderungen für alle im Team verfügbar zu machen. Beim nächsten Öffnen des Tools werden die neuesten Daten automatisch geladen!

4️⃣ PDF exportieren

Klicke auf "📄 Als PDF exportieren" um alle Paragraphen als übersichtliche PDF zu speichern. Perfekt zum Ausdrucken! Footer: FL-BE_07/25_Justin_Lee_Probis

⚡ Keyboard Shortcuts

  • Strg+S - Speichern
  • Leertaste - Play/Pause (im Teleprompter)
